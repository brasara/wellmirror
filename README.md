# WellMirror

WITSML synchronization for engineers and integrators — a desktop
application that mirrors wells, wellbores, logs, and trajectories between
WITSML 1.4.1.1 stores, continuously and with read-only access to the source.

## Releases

Installers for Windows and macOS are published under the **Releases** tab of
this repository.
